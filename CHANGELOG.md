# Changelog

## 0.1.0 — 2026-10-28

First public release.

- Static README checks for local paths, package scripts, Python files/modules, requirements references, and literal shell scripts.
- Terminal, JSON, Markdown, and portable HTML reports, with explicit unverified results.
- Hidden HTML-comment handling and escaped terminal control characters.
- A reproducible study of eight pinned public repositories, retaining no-coverage and historical samples.
- 83 automated tests and package smoke checks on Python 3.10, 3.12, and 3.14.

This release does not execute project commands or establish successful installation. The study provides compatibility evidence, not external adoption or endorsement.
