How to read this report

Broken reference

A supported static check found a mismatch in the supplied repository snapshot. Review the command and the evidence together.

Reference found

The referenced file, directory, or script exists. Its behavior, dependencies, and execution were not tested.

Needs a run

The step could not be resolved with the supported static checks. Review it and run it in an appropriate environment.

Scope matters. ColdStart does not verify dependency installation, network services, credentials, operating-system compatibility, or program behavior. Each shell block starts at the repository root; paths are followed only within the supported static command subset. This report reflects the local files inspected, not a guarantee about a release or fresh clone.
